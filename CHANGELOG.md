## 0.0.1

* Initial release of `flutter_simple_access_engine`.
* Added ABAC permission normalization and access evaluation with exact, feature wildcard, and global wildcard matching.
* Added `AbacProvider`, `Abac.of(context)`, `AbacScope`, `BuildContext.can()`, `AbacVisibility`, and `AbacPage`.
* Added a complete `example/` app demonstrating granted, denied, and loading states.
* Added unit and widget test coverage for core permission logic and widget behavior.
* Added package documentation in `README.md`.
